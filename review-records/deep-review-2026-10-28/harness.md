# Deep review of 2026-10-28: harness (HR)

Reviewer: `harness`, an agent of another configuration, reading cold. Scope: `harness/govharness/`, `harness/tests/`, `harness/README.md`, `harness/records/`, the docstrings, and STND.HARN (`rendered/STND.HARN.md`), judged as an optional, lightweight, read-only query layer for an agent in a CSQ3 or CSQ4 project.

## Scope and method

Read: the brief, CUSTODIAN.md, the README, STND.HARN 1.5, `cli/`, `query/`, `core/corpus.py`, `checks/drafting/tables.py`, `workflows/solve_store.py`, `tests/__init__.py`, records (dependencies, units 0014 and 0018, decision 0002, review 0006), and the Notes of STND.DRAFT, STND.IDENT, STND.DFLT, and STND.CLASS. Ran 40 read-only commands on the live corpus (`show`, `find`, `context`, `verify`, `check`, `pairs`, `compose --check`), timed by `time.perf_counter`, with exit codes and byte counts recorded; ran them again from `/` against a read-only copy of the corpus with `PYTHONPATH`, against a copy without `ledger.jsonl` and manifests, and with a fresh `HOME` to watch for writes. Grepped the code, tests, and README for every identifier in a `withdrawn` field and for the unit 0018 vocabulary. Ran three test modules (1.5 s together). Python 3.14 only was available, so the 3.11 claim was checked by inspection (`datetime.UTC`). Nothing was changed outside this file.

## Convenience-layer recommendations

The smallest set of changes that makes the harness a good optional query layer for an agent in a CSQ3 or CSQ4 project:

1. **Fix the ranking (HR-1).** Provisions, terms, and Terms sections before Notes. This one change turns `find` and `context` from a Notes finder into the two commands an agent most needs: `context WORDS --in-force` for "what applies to this action" (today it already answers "destructive action" well: 14 provisions in 7 KB) and `find WORDS` for "which provision or term is this".
2. **Print a document whole (HR-2).** `show STND.PY --all` answers "what applies to Python code at CSQ3" in one call, as the reading copy does, without the agent reading corpus files.
3. **Install it (HR-5).** A `pyproject.toml` and `GOVHARNESS_ROOT`, so a project's agent instructions say `govharness show ID`, `govharness find WORDS`, `govharness context WORDS --in-force`, and nothing about directories.
4. **Write nothing by default (HR-4).** Cache opt-in. Then every command an agent runs is read-only in fact as well as in name.
5. **Shorten `show` (HR-11).** Fold the citing Notes into one line.
6. **A ten-line README section "For an agent in a project"**, above the custodian's toolkit: the three commands; the recipes for the questions the custodian names ("what applies to language X": `show STND.X --all`; "before a remote push": `context remote write --in-force`, then `show LEX.remote-write`; "what does the term mean": `find WORDS` and `show LEX.slug`; "what promotion to CSQ2 owes": `show STND.CLASS.10`, then `find CSQ2 --in-force`, until an `onset` command exists, HR-3); the two-second test subset (HR-14); and the sentence that nothing depends on the harness (GOV.38).
7. **Remove the unit 0018 leftovers (HR-7)** and the restated provisions (HR-8), so the README stops drifting from the corpus.

Everything else (`verify`, `check`, `compose`, `manifests`, `references`, `ledger`, `sign`, `rehearse`, `pairs`) is the custodian's toolkit. It is sound and fast, and it belongs in a second README section, not in the agent's path.

## Systemic observations

The harness does what unit 0018 says it is for: it is read-only in the query commands, standard-library only, fast (every query under half a second, `verify` under three seconds), and it runs against a read-only corpus in another directory, even a partial one. The code is clean; the four dead functions are the only leftovers of the environment derivation, and the README holds the rest (HR-7).

The weakness is at the surface an agent touches. The retrieval design of unit 0005 and review 0006 ranks by distinct words held, which the corpus's own growth has turned against it: Notes sections are now the longest texts and dominate every multi-word question (HR-1), and no command returns a document's provisions whole (HR-2). Both are small changes in `retrieval.py`. The README, written for the custodian, buries the three agent commands under 320 lines of ledger, signature, and solver detail, and restates provisions in its own words (HR-8); a reader in a project cannot tell which ten lines are for them.

For CSQ3 and CSQ4 work, the harness asks nothing of anyone: no command must be run, no file is written, and a project may carry only the standards it uses. The one place where the harness and the corpus lean on each other is the hand-kept lists and command names (HR-9), and the one obligation whose machinery is out of proportion is STND.HARN.28 (HR-12), which bears on the custodian's rounds, not on a project. Promotion from CSQ4 to CSQ2 is answerable today only through STND.CLASS.10, because onset below LVL0 is prose; the rule for deriving it exists in AGENT's Notes, and a derived onset would make it a field the harness verifies, as it verifies `rank` (HR-3).
