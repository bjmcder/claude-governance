## Defect

1. **Cited document: the exclusions contradict the corpus.** Text: "A name inside quotation marks, a code span, a column headed Example, the section References, or the revision history does not count, nor the word LVL0 where it names a level." The code applies these exclusions to bare names only. `references.cited_documents` still derives a citation from a code span, an Example table, and a revision history, and g.25 requires those rows. In STND.IDENT, QA is cited only in the revision history, and STND.CLASS only in the Example table, yet both are References rows. Read literally, neither is a cited document, so STND.DRAFT.34 fails those tables. Also, AGENT, CPS, and HDES.ASIC write "LVL0" for the constitution ("what LVL0 requires"), not a level, and have no LVL0 row. The term would make LVL0 a cited document there, while the code never counts it (`NOT_NAMES`). Replace the added sentence with: "Where a document is named by its identifier and not cited, the name counts except inside quotation marks, a code span, a table with a column headed Example, the section References, or the revision history, and the word LVL0 written alone never counts."
2. **Table of Example.** The term excludes "a column headed Example". `without_example_tables` drops every row of a table that has such a column. The replacement in item 1 follows the code.

## Should-fix

1. **"alone or in parentheses".** The code counts any bare identifier at LVL1 to LVL3, so "(HW, GOV)" fails g.25. `references` derives only `(HW)`, written alone in parentheses. The term's clause adds nothing and misleads. The Checks sentence "the document's identifier in parentheses" has the same imprecision. Replace in the term: "or named by its identifier in their text"; in Checks: "or the document's identifier written alone in parentheses".
2. **Checks, L9.** Text: "the provision of this standard that the check enforces is binding". Several checks have two provisions of different mode: g.20 (STND.DRAFT.30 default, .31 binding). The code (`binding_keys`) fails when any binding provision names the check. Replace with: "a binding provision of this standard names the check in its field `checked_by`". The unit 0017 record leaves this reading to the custodian, so the draft takes a side (see question 1).
3. **Floor arguments missing (GOV.11, CUSTODIAN.md item 3).** The IDENT 1.4 rationale gives none for STND.IDENT.24, which binds because it instantiates GOV.37. The STND.DRAFT rationale gives none for the widened term. Compare STND.HARN.31 and .32, which have them. Add to the IDENT rationale: "STND.IDENT.24 binds, because it instantiates GOV.37, and raises no floor (GOV.11): it asks the custodians one list of identifiers, only when a revision withdraws a provision of a part, and it asks nothing of a project." Add to the DRAFT rationale a sentence that the term lets STND.DRAFT.34 reach no obligation beyond the citation that PRIME.15 already requires, and that STND.DRAFT.3 relaxes. Put both to the custodian.
4. **Sentence.** "full stop" is not American usage. Write "a period, a question mark, or an exclamation point". The term also leaves out that the harness ends a sentence at the end of a line of a list or a table cell, and that "." followed by a lowercase letter or a backtick does not end one (`TERMINAL_RE` needs a capital, "(", or a quotation mark). State the first, or have draft-status item 8 say the code differs. The checks other than g.4 still split at ; and : (draft-status item 8 already owes this).
5. **STND.DRAFT.3.** "a column of a table whose entries are expressions" is not decidable: "expressions" is undefined, and "Replace with" (STND.DRAFT.29) or "Expresses" (STND.DRAFT.1) could count. The columns that need the exemption hold modals or excluded expressions (STND.DRAFT.1, .7). Replace with: "Outside a column whose entries are modals or excluded expressions, a modal or an excluded expression that a provision mentions without using it SHALL be enclosed in quotation marks (LVL0#normative-language)." The provision is clearer for it, and the code owed in draft-status item 7 can follow it.
6. **Checks, v.8 (STND.IDENT).** The new sentence is true but incomplete. The check also fails a listed identifier of another document, and a cited identifier that names no provision and is not listed (the only way a withdrawn highest number shows). Replace with: "The check v.8 compares the numbered provisions of each document with its field `withdrawn`, and those of each part of the constitution with the field `withdrawn` of the constitution: a gap in the numbering that the field does not list, a listed identifier that names a provision or is not the document's own, or a cited identifier that names no provision and is not listed, fails."
7. **STND.DRAFT.22 and v.8.** v.8 passes a citation of a listed (withdrawn) identifier, which does not resolve to a provision. v.8 therefore verifies STND.DRAFT.22 in part. Keep it in `checked_by`, but say in the rationale that it is partial.
