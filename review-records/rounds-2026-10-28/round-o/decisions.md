## The field (C7, second bullet)

**Definition**, in STND.DRAFT#representation-in-the-harness, where every field of a provision is defined, after `checked_by`:

> - `onset`: the class from which the provision applies under STND.CLASS.10, written as one class, `"CSQ3"`, or, where a part starts at a more severe class than the rest, as a list of the class of the provision followed by one pair of a part and its class for each such part, `["CSQ3", ["sentence 2", "CSQ2"]]`. A part is `sentence N`, the Nth sentence of the body outside its tables, counted at terminal punctuation, or `row CELL`, the one row of a table of the body whose first cell is CELL. Each class is CSQ0 to CSQ3. The value `null` marks a waivable provision that applies at every class, or a permission. A binding provision and a provision of LVL0 carry no field. The harness fails a malformed value, a field on another item, a part that names no sentence or no one row of the body, and, once one provision carries the field, a waivable provision below LVL0 without it.

**Why this is the least that serves the rule.** The rule assigns a class to each part, so the field needs exactly three things, and has nothing else:
- one class for the whole provision, the common case (735 of 765 values that give a class);
- a way to give a later class to a named part, since 30 provisions start in part later than the rest; the part is named by what a reader can point to, a sentence or a table row, which are the only units at which the corpus's Notes have ever stated onsets;
- nothing where the provision binds, so that the binding provisions and the LVL0 provisions are untouched, and the rows of STND.CLASS.10 are not restated in LVL0 (GOV.31); `null` where a waivable provision applies at every class, so that the harness can tell an onset left out from one that is "every class" (review, item 6).

It has no earlier-part form: a part that starts earlier than the rest is not needed, because the class of the provision is its earliest class. It has no CSQ4: STND.CLASS.10 lets work of CSQ4 omit every obligation above the floor but those it names, so a field cannot give CSQ4 force (review, D3). It has no field for the reason of an onset, which stays in the Notes, read once per document, and no per-clause part, since a clause cannot be pointed to without restating the sentence. A rejected alternative was to leave CSQ3 implicit for every waivable provision, which would have set only about 160 fields; the brief and the ruling ask the onset of each provision to stand in its front matter, so that `show` gives it without a derivation and an omitted field is not read as CSQ3 by accident. The harness checks what it can read: a well-formed value, a field only on a waivable provision below LVL0, and parts that exist; which row a part asks for is a reader's judgment, and the table in `round_o_fields.py` gives the source of each value so that the review can check it.

**The fields set.** 774 rows, one per waivable provision below LVL0: 765 that give a class and 9 `null` (STND.CLASS.10, STND.CLASS.18, STND.CLASS.21, and STND.CLASS.23, which apply at every class; the permissions STND.ANNEX.1, STND.DEPS.10, STND.DOCS.6, STND.DOCS.7, and STND.WPROC.11, which STND.CLASS.10 does not stage). `gen` refuses a value on a provision whose only modal is MAY. `apply_fields` refuses a waivable provision without a row, so a provision that round c adds is caught.
