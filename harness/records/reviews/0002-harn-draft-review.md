## Method

1. Read the draft, the rules above, and the code each provision specifies.
2. Tested every statement against the code and the live ledger. Wrote a separate implementation of the content hash and the entry hash from the redrafted definitions. It reproduces the latest pin of all 7 ledger scopes and the hash of all 41 entries.
3. Redrafted, regenerated, and ran `verify`, `check --no-z3`, `manifests --check`, `references --check`, `compose --check`, and the test suite.
