The package metadata of each crate of the work SHOULD state its edition and the oldest release of the Rust toolchain that it supports (SIMPL.6, REPRO.9). The checks of each change SHOULD build and test each crate of the work with that oldest release, and with the release of the toolchain that builds the reported results and the releases of the work (VV.8). Other than for high-assurance code whose edition and toolchain STND.CODE.19 fixes, a check that reports its failure without blocking a change SHOULD build and test the work, at the interval that the repository configuration sets, with the newest stable release of the toolchain and with the newest revisions of its dependencies that their declared ranges admit (VV.8, STND.CODE.19).
