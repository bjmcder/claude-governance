Where untrusted input supplies a subscript, the check that rejects an invalid value of it SHALL be a test in the code that no execution setting removes, made against the bounds of the array or the extent that the caller passes for an assumed-size dummy array, at the entry of the untrusted input or at the first point after it at which that bound is known (PRIME.4, DSGN.2).
