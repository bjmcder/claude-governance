Where a source file of Fortran uses a form that the check of STND.FTN.1 reports, or does not meet STND.FTN.4, STND.FTN.5, STND.FTN.6, STND.FTN.10, STND.FTN.12, STND.FTN.13, STND.FTN.14, or STND.FTN.25, the repository configuration SHOULD hold an entry for that file in the legacy list, with those forms and provisions and a reason for each provision and for each class of forms (REPRO.7). Other than an entry that the change that adopts this standard, a change of a compiler or of the revision in force, a revision of this standard, or a change that incorporates external code into the work makes necessary, a change SHOULD NOT add an entry to the legacy list (DSGN.3).
