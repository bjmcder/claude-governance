Other than where a qualified revision fixes it, the Julia revision of the production configuration and of the checks of each change SHOULD be the latest patch release of the reference version (VV.8, REPRO.9). Where the bounds of STND.JL.2 admit a minor version earlier than the reference version, the checks of each change SHOULD also run on the earliest version that they admit (VV.8). At the interval that the repository configuration sets, a check that reports its failure without blocking a change SHOULD run the tests on the newest stable release and on the newest prerelease of Julia (VV.8).
