The repository configuration SHOULD name one reference version (REPRO.2). The reference version SHOULD be the latest stable minor version of Julia that is consistent with the rest of the computational environment, as STND.DEPS.3 asks (REPRO.9, SIMPL.4). Where a qualified revision of Julia fixes the reference version, the reference version and the Julia revision of the production configuration MAY stay at that revision (REPRO.9).
