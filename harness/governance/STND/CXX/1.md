The repository configuration SHOULD name a published guide of C++ practice, at a recorded revision, as the reference for the C++ practice of the work, and list each of its rules that the checks of STND.CXX.25 exclude and each from which the work knowingly deviates, with the reason (INTPR.1, REPRO.7). Where this standard and that guide differ, the work SHOULD follow this standard (INTPR.1).
