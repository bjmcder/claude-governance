Each owned resource SHOULD be released by the destructor of the object that owns it, or of the last of the objects that share its ownership (DSGN.14). A raw pointer SHOULD own the object it points to only inside the implementation of a resource handle, or of an object that owns an owned resource under STND.CODE.25 (DSGN.14). Each raw pointer that owns the object it points to SHOULD be declared through a type alias that the static checks of STND.CXX.25 recognize as marking ownership (DSGN.3).
