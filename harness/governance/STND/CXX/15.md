The documentation comment of each declaration in a header that another component uses SHOULD immediately precede that declaration, in a form that a documentation tool of the work extracts (INTPR.1, INTPR.3). In addition to what STND.CODE.3 asks, that comment SHOULD state the owner and the period of validity of each pointer, reference, view, and iterator that the declaration returns or keeps beyond the call, each C++ exception or error value by which it reports failure, and whether concurrent calls to it are safe (DSGN.1).
