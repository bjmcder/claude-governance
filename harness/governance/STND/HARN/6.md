The governance ledger, and each ledger that a harness is asked to read or append to, SHALL be a UTF-8 file of one transaction per line, each a JSON object with sorted keys, no white space between tokens, and non-ASCII characters unescaped; the governance ledger is the root "ledger.jsonl" (GOV.36).
