Other than for a release of Python that STND.CODE.19 fixes, the checks of each release of a distributed package SHOULD run on the oldest declared release of Python with the oldest declared release of each dependency that it uses, and on the newest releases of Python and of those dependencies that its declared ranges admit and that are consistent with one another (VV.8).
