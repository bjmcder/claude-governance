Where a run of a numerical method uses a parameter value outside the domain of validity that the method's verification establishes, the departure SHALL be reported to the operator during the run (INTPR.10, INTPR.7). Each reported numerical result that such a run computes SHALL state the departure (INTPR.10, INTPR.9).
