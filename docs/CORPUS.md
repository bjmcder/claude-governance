To rebuild and query (Python 3.11+, standard library):

```bash
project_read claude/harness/harness-ledger109.tar.xz.b64   # returns a local file, $F
mkdir harness && base64 -d "$F" > h.tar.xz
sha256sum h.tar.xz            # must match the hash above
tar -xJf h.tar.xz -C harness && cd harness
python -B -m govharness verify governance
python -B -m govharness show governance STND.KNOW.5
```

The copies go stale with the next ledger entry. Whoever appends one refreshes them: run `claude/harness/build_copies.py` from the repository root, rebuild the bundle, upload both, and update this file.
