# Adoption folder

This folder holds what the repository commit of ledger entries 46 to 109 needs, with the corpus in `claude/harness/harness-ledger109.tar.xz.b64`: `harness-unit0006.patch` (harness code for STND.HARN.26 to .28), and `COMMIT_MSG.txt`. `claude/harness/CORPUS.md` explains how to rebuild and verify the corpus, and how to rebuild a patch against e2b3563 if one is wanted.

`pending-ledger-entries.jsonl` holds, as its line 4, the human owner's standing authorization for read-only research retrieval (10,000 items and 10,000 MB per research effort), which is entered once in each covered project's own ledger, with `<project>` replaced. Its other lines are ledger entries 46 to 51, already applied.

Superseded bundles, patches, and drafts are kept outside the project in the archives project-archive-superseded-2026-10-11 to -2026-10-18, project-archive-stale-2026-10-18, and the later archives that claude/scientific-software-constitution.md lists, the latest project-archive-loose-harness-and-patch-2026-10-23.
